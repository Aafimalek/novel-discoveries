# G449: kernel-checked arithmetic and exact four-colour DIMACS bridge

This follows the independent [Heule–Przybocki G449](https://github.com/bprzybocki/G449) pilot. The graph is from their [paper](https://arxiv.org/abs/2611.28518); the published result and upstream data are theirs. The method here is a calibration for exact graph certificates, not a novelty claim or an improvement to the unrestricted 6–7 bounds.

## Reproduce with plain Lean 4.36.0

Place the original scripts in a writable directory, alongside replay.py from the prior pilot. Download G449.k21 and G449.s6 from upstream commit 125bfda97ed1d336f84694de04dedcfb349c5164 as described there. Do not commit the downloaded or generated coordinate data. Run ./build-checks.sh, setting LEAN to the desired Lean 4.36.0 executable if necessary. All certificate stages documented here import only Init and the previous local modules.

## Verified arithmetical scope

- The kernel checks all 49 steps of a spanning forest of the signed rotation orbits, 54 rows of the power reduction table, and the integer norm computation on all seven representatives.
- The kernel checks all 2,198 signed edge-to-direction relations on the actual input coordinate rows, their count, the palette range, and the supplied proper five-colour assignment on the whole published edge list. Arithmetic is sharded into 28 independently compiled short batches. The previous Python audit independently derived and matched the entire sparse6 edge list; auditors should retain both the Lean coordinate check and the input-pinning checks.
- FourColourCNF.lean proves that a proper four-colouring supplies an assignment to the numbered DIMACS-style clauses; G449Formula.lean instantiates it on the actual generated pair list. The resulting Lean-generated bytes match the independent Python CNF, SHA-256 289d6b5d6922264a38075fc39ea42eab19044ff4b006a5c1b6fe475363bc2e62 (1,796 variables, 9,241 clauses). The logical implication depends only on propext and Quot.sound.
- No four-colour UNSAT certificate is claimed in Lean. The authors' original check is streamed LSR, not part of this build. No unrestricted result follows from this calibration.

Only original source code is provided. Every data module, including EdgeData00 through EdgeData27, is generated locally from pinned artefacts.
