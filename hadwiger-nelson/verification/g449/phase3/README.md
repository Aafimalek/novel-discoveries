# G449: kernel-checked arithmetic and exact four-colour DIMACS bridge

This follows the independent [Heule–Przybocki G449](https://github.com/bprzybocki/G449) pilot. The graph is from their [paper](https://arxiv.org/abs/2611.28518); the published result and upstream data are theirs. The method here is a calibration for exact graph certificates, not a novelty claim or an improvement to the unrestricted 6–7 bounds.

## Reproduce with plain Lean 4.36.0

Place the original scripts in a writable directory, alongside replay.py from the prior pilot. Download G449.k21 and G449.s6 from upstream commit 125bfda97ed1d336f84694de04dedcfb349c5164 as described there. Do not commit the downloaded or generated coordinate data. Run ./build-checks.sh, setting LEAN to the desired Lean 4.36.0 executable if necessary. The arithmetic stages import only Init and the previous local modules; see below for the separate Mathlib geometry build.

## Verified arithmetical scope

- The kernel checks all 49 steps of a spanning forest of the signed rotation orbits, 54 rows of the power reduction table, and the integer norm computation on all seven representatives. The generic OrbitTransport theorem proves that any property preserved by signed rotation transfers from these seven roots to every indexed direction. AllNormsScan additionally checks all 49 reduced integer norms independently of the orbit argument.
- The kernel checks all 2,198 signed edge-to-direction relations on the actual input coordinate rows, their count, the palette range, and the supplied proper five-colour assignment on the whole published edge list. LinkedNorms then proves that the reduced norm of each actual raw endpoint difference is exactly the constant 2401. Arithmetic is sharded into 28 independently compiled short batches. The previous Python audit independently derived and matched the entire sparse6 edge list; auditors should retain both the Lean coordinate check and the input-pinning checks.
- FourColourCNF.lean proves that satisfiability of the numbered DIMACS-style clauses is equivalent to proper four-colourability; G449Formula.lean instantiates that equivalence on the actual generated pair list. The resulting Lean-generated bytes match the independent Python CNF, SHA-256 289d6b5d6922264a38075fc39ea42eab19044ff4b006a5c1b6fe475363bc2e62 (1,796 variables, 9,241 clauses). The equivalence depends only on Lean’s three standard axioms; the implication from UNSAT to non-four-colourability uses just propext and Quot.sound.
- No four-colour UNSAT certificate is claimed in Lean. The authors' original check is streamed LSR, not part of this build. No unrestricted result follows from this calibration.

Only original source code is provided. Every data module, including EdgeData00 through EdgeData27, is generated locally from pinned artefacts.

## Verified Euclidean closure (requires Mathlib)

After the arithmetic build, build CyclotomicWitness.lean from the first pilot, then DirectNorm.lean and the checked version of Rotation42.lean from the second pilot. Finally build CompleteG449Geometry.lean from this package with the same LEAN_PATH, including the Mathlib build. The checks here used official Lean 4.36.0. The final module built successfully locally and printed only Lean's standard axioms.

- all_49_direction_displacements_unit proves unit Euclidean length for every one of the 49 signed-direction classes. The computational proof checks the rank-decreasing orbit transfers from seven numerical representative norms, and the separate arithmetic scan cross-checks all 49.
- geometry_and_five_colouring proves actual Euclidean distance one for every one of the 2,198 published edge pairs, from the original exact coordinate rows, and proves the supplied assignment is proper and uses at most five colours on those vertices.
- The complete edge geometry and numbered DIMACS semantic equivalence do not imply that the original graph requires five colours unless the UNSAT side is also proved; the streamed LSR refutation remains an external result, not a Lean replay. This checks the reported edges, not in Lean the absence of all omitted edges or uniqueness of all embedded points; those two checks are part of the independent Python audit.
