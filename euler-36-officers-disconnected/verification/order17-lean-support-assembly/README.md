# Kernel-checked support-prefix valuation for Euler size 17

This stage handles the shared non-triple prefix of the archived branches.
It does not close further SAT cases or handle case-specific geometry.

1. `EulerSupportWords.lean` enumerates the 36 supporting words for each
   coordinate pair in the intended free-coordinate order. It proves this
   enumeration is injective, lands in the supports and exhausts them.
   Linearity gives at most one chosen word among the inputs of every
   support counter.
2. `EulerSupportValuation.lean` installs all 216 auxiliary grids (35
   states each) at base (1513+35(\mathrm{pairNumber}-1297)).
   It preserves all IDs outside 1513–9072 and proves the physical
   backward projection clause, the 36 forward implications, and the
   ordered AMO clauses for every pair.
3. `EulerArchivePrefix.lean` models the complete 31,752-clause first
   prefix, including each word's six-pair saturation clause. A linear,
   saturated design produces one numeric valuation satisfying the prefix.
4. `EulerCommonCounterAssembly.lean` joins the support valuation with
   the existing separate exact-cardinality valuation. It uses the fact
   that the two installers touch disjoint variables, proving all 34,564
   shared prefix+counter clauses satisfied by the same valuation. The
   final valuation preserves every input word/pair bit and all unary
   degree threshold values.

The ordinary emitted `archivedSupportPrefix` was compared in signed
integer order to positions 1–31,752 of all seven original size-17
CNFs that had kernel-checked refutations at this checkpoint. See
`prefix-byte-audit.log`. This is an independent, exact parser/reference
comparison, not part of the Lean proofs about the modeled clause list.

## Reproduction

Use Lean 4.36.0 and the matching Mathlib with the previously verified
geometry-cardinality modules (`EulerGeometryCounters`,
`EulerCounterSlots`, `EulerNumberedCounters` and
`EulerArchivedCounterValuation`) and their dependency path. Compile
in the above order. To reproduce the separate exact byte check:

```sh
lean --run EmitSupportPrefix.lean > emitted-prefix.txt
python compare_support_emission.py emitted-prefix.txt ORIGINAL.cnf ...
```

The output digest and exact build audits are included; the output itself is regenerated by the command above. The independent byte check needs the matching original CNFs. The
printed theorem axiom audits are only `propext`, `Classical.choice`
and `Quot.sound`; no native decision axiom is used.

Remaining tasks include normalized case selection, the remaining cut
and symmetry clauses, and full formal proof coverage of the original
size-17 refutations. This package alone does not prove the exact
minimum of the puzzle in Lean.
