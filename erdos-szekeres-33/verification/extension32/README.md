# One-point extension of an explicit 32-point Erdős–Szekeres witness

## Restricted result

The exact integer witness in `points.csv` has distinct first coordinates and
no convex heptagon. No 33rd point can be added to this witness in general
position without creating a convex heptagon. The same exclusion holds for
realizations with the same sorted triple signs. It does **not** exclude other
32-point order patterns inside a hypothetical 33-point counterexample, and it
does not solve the general 33-point Erdős–Szekeres problem.

The coordinates are generated, not taken from a new bound or claimed as a new
geometric construction. They instantiate the classical Erdős–Szekeres
cup–cap cluster method from [the original paper, §2](https://www.renyi.hu/~p_erdos/1960-09.pdf).
The program uses its own simple integral translations: for (k=1,ldots,6)
the (k)-th cluster is built by the Pascal recursion on ((k,7-k)), with both
component abscissa lists made consecutive. The right component moves right by
the left size and vertically up by (1+N(max y-min y)), where (N) is the
sum of component sizes. The resulting six clusters have sizes (1,5,10,10,5,1).
Cluster (i), zero-based, is translated by ((iL,L(i^2-20i))), where
(L=100(1+max(x+y))^2) over all unshifted cluster points. No numerical
approximation or randomized tuning is used. The output is verified directly
rather than relying on the coordinate choices' analysis.

A separate C++ program checked all 4,960 triple determinants and computed
monotone-chain convex hulls for every one of the 906,192 six-subsets and
3,365,856 seven-subsets. It found exactly 39,648 convex six-subsets and no
convex seven-subset. This is independent of the Python generator's
determinant parity search.

## One-point extension encoding

For every insertion slot (0,ldots,32) in increasing first-coordinate
order, fix all old orientation signs. The variables are:

- 496 signs of sorted triples consisting of two old points and the new point;
- 4,960 auxiliary nonconvexity bits for four-sets containing the new point.

For each such four-set specialize the eight compact local clauses to its
one known old-only triangle sign. The clauses require both the actual
left-to-right signotope condition and correct nonconvexity parity.
For each old convex six-set, add the disjunction of the 20 nonconvexity
bits obtained by adjoining the new point to its old three-subsets.
An old nonconvex six-set does not need a clause: convex position is
hereditary. The base witness has no old convex seven-set.

If the added point has the same first coordinate as an old point,
perturb the added point horizontally by a sufficiently small nonzero
amount. General position makes all relevant determinants nonzero and
finitely many strict signs persist by continuity. Thus the 33 strict
insertion slots cover all potential extensions. An arbitrary satisfying
assignment would not by itself provide a real realization, but independent
UNSAT suffices to exclude a slot. Every slot's 69,408-clause instance was
reported UNSAT and independently replayed to `s VERIFIED`. The trimmed
certificates are replayed against the exact original (untrimmed) formulas.

The accompanying Lean project proves the geometric four-set reduction,
the orientation parity test, the strict-order signotope condition, and
the abstract compact truth table and clause-family semantics. The
specialized numbered DIMACS and DRAT replays here are **not** verified
end to end by the Lean kernel.

## Reproduce

Use Python 3.10 or later, a C++17 compiler, GNU coreutils, and
[DRAT-trim at commit 2e3b2dc0ecf938addbd779d42877b6ed69d9a985](https://github.com/marijnheule/drat-trim/tree/2e3b2dc0ecf938addbd779d42877b6ed69d9a985).
The original proofs were generated by [Kissat release 4.0.4](https://github.com/arminbiere/kissat/releases/tag/rel-4.0.4),
built in a quiet configuration (omit `-q` on its command line).
The checker, not the SAT solver, is trusted for the certificate tests.
The replay regenerates about 139 MiB of DIMACS files; they are not stored
in the publication bundle.

```sh
DRAT_TRIM=/path/to/drat-trim bash verify.sh ./generated
```

To repeat the original SAT search and independently check its traces:

```sh
KISSAT=/path/to/kissat DRAT_TRIM=/path/to/drat-trim \
  bash replay_extension.sh ./resolve
DRAT_TRIM=/path/to/drat-trim \
  bash trim_extension_proofs.sh ./resolve ./new-cores
```

`DIMACS.sha256` hashes the exact generated formulas and coordinates;
`ORIGINAL.sha256` also records the original native proof hashes;
`CERTIFICATES.sha256` hashes the included trimmed certificates.
`cases.tsv` gives a per-slot summary. The archive stores all 33 proof
objects and the checked replay logs.
