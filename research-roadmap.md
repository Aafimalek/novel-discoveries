## Problem statements and context

**Hadwiger–Nelson.** Does coloring the Euclidean plane so that points at distance one receive different colors take six colors or seven? The published research release gives a Lean-checked obstruction to five colors; the exact value is still listed as open in [Formal Conjectures](https://github.com/google-deepmind/formal-conjectures/blob/main/FormalConjectures/ErdosProblems/508.lean). Aim for a genuine six-coloring or an explicit finite unit-distance graph that requires seven. A separate constructive milestone is an explicit graph that is not five-colorable; that would make the known lower bound constructive, not resolve six versus seven. See the [five-color obstruction](https://github.com/openai/math/tree/main/preprints/The-Euclidean-plane-is-not-five-colorable-September-23-2026) and the [November 2026 finite five-chromatic construction](https://arxiv.org/abs/2611.28518).

**Erdős–Szekeres: the 33-point problem.** Must every set of 33 points in the plane, no three collinear, contain seven points in convex position? This is the first unresolved exact case. An explicit set of 33 points avoiding such a heptagon would disprove the classical prediction; a proof no such set exists settles this case. The most useful intermediate target is a checkable reduction of the possible point-order configurations, not a floating-point search. [33-point problem](https://arxiv.org/abs/2512.24061) · [November 2026 general upper-bound advance](https://arxiv.org/abs/2611.29344).

**Collatz.** Repeatedly halve even positive integers and replace odd ones by three times the number plus one. Must every starting integer reach 1? A meaningful partial goal is a uniform new bound on a precisely defined family of trajectories or cycles, not merely more tested starting values. [Tao's almost-all theorem](https://arxiv.org/abs/1909.03562) and [recent computational work](https://link.springer.com/article/10.1007/s40993-026-00811-5) set separate theoretical and numerical baselines.

**Caccetta–Häggkvist, directed triangles.** Must an oriented graph on n vertices with at least n/3 outgoing edges at every vertex have a directed triangle? This is an accessible statement with a substantial graph theory payoff. A possible first result is a structural theorem reducing the search for triangle-free near-extremal configurations. See [recent work on directed cycles](https://arxiv.org/abs/2611.22909) and [the flag-algebra approach to triangles](https://arxiv.org/abs/0908.2791).

**P vs NP.** A solution would be a landmark, but the gap between a useful restricted result and the full question is enormous. I would not make it the first project without a specific circuit or proof-complexity target. [Clay Mathematics Institute](https://www.claymath.org/millennium/p-vs-np/).
